# Fuzzy Relation Matrix Learning via Gradient Descent

A MATLAB implementation exploring differentiable smooth approximations and **Stochastic Gradient Descent (SGD)** optimization for fuzzy relational composition problems.

## 📂 Repository Structure

| File | Focus | Description |
| :--- | :--- | :--- |
| `fuzzy_matrix_sgd.m` | **Fuzzy Relational Optimization** | Formulates smooth approximations to max-min composition operators and updates relational parameters iteratively via gradient-based steps. |

## 🛠️ Tech Stack
* **Language:** MATLAB
